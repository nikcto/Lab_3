# Валидатор технологического режима нефтяной скважины (вариант Б)
Программа запрашивает технологические параметры скважины, проверяет границы
значений через иф элсе`, организует циклический ввод до получения
корректного значения, классифицирует скважину по обводнённости и определяет
статус режима по депрессии на пласт. Маршрутизация меню и действий выполнена
через `match-case`.

## Требования

- Python 3.10+
- Git
## Запуск

python -m venv .venv
.\.venv\Scripts\Activate.ps1
$env:PYTHONPATH="src"
python -m well_valid.main
